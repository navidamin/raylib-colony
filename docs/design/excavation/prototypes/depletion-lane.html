Excavation · phase 4 · the shaft bar's second lane

Column or Block

A shaft opens an 8×8 block — 64 spots, four depths each. The lane beside the strata has room for one reading of that. Show the column you are standing in and it answers move the machine?; show the block and it answers sink another shaft?. Work a spot and watch which one moves.

Click a spot on the block to move the machine. The lanes read the same ground three ways.

A — the column

How much is left under the machine?

Four bars, one spot. Empties in a minute of work and redraws completely the moment you click elsewhere.

Cannot tell you the shaft is spent — you would have to visit all 64 spots to find out.

Answers: move the machine

B — the block

How much is left in this shaft's ground?

Four bars, 64 spots averaged. Barely twitches while you work one spot, and falls over hours.

Cannot tell you to move — a spot you have emptied and its untouched neighbour read as one number.

Answers: sink another shaft

C — both

Both, on one axis.

The block is the fill; the column is the bright tick riding on it. Two time-scales, one lane, and the gap between them is itself the reading.

Wide gap = this spot is spent but the block is not. No gap = the shaft is done.

Answers: both — recommended

Why this is not a free choice. The two readings move on different clocks. A spot is worked out in a minute; a block of 64 takes hours. A lane showing only the column is a needle that never settles, and one showing only the block is a dial that never moves — each is useless for the decision the other serves.

What C costs. One more channel in a 120 px strip, and a rule that the tick must never be mistaken for the fill: the block is rock-coloured because it is ground, the column tick is amber because it is where the machine is (Dark Plating §1.2 — amber is always machinery).

The ground here is real in shape, not in numbers. Spot richness is a Gaussian shoot on an 8×8 block, the same form ProspectingGrid generates — so the block has a rich middle and poor corners, and the lanes disagree the way they would in the game. The rates are picked for a readable demo, not balanced.
