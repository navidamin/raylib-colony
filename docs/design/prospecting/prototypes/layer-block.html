Layer Block

Four lunar strata as one cut body — regolith over megaregolith over fractured rock over intact basalt, 0–120 m, with the borehole bar on the same depth axis. Nothing here is data: the interfaces are generated, so every lever below changes the ground itself. Click a layer to take off everything above it and leave it translucent; Esc puts the stack back.
